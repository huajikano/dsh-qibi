# 起笔写作台（QiBi writing desk）

在 DSH 左侧栏打开一枚「起笔」图标，点进去是起笔书稿的原生工作台；同时向 Agent 注册一组 `qibi_*` 工具，让它能读、也能写你的书稿。

## 它做什么

- **连续性自动整理**：一键从本章已保存正文补齐摘要和追加有依据的新伏笔，直接保存；可按作品开启在面板标为已发布时自动运行。默认关闭，普通自动保存不触发；原有笔记和正文保留，并发变化拒写，分卷仍可选手动管理。
- **普通作者操作**：连续性提供伏笔列表与高级 JSON；外观提供舒适/紧凑密度；人物可按起止章分批提取并合并候选；蒸馏按四步指引完成素材、对话生成、刷新和应用。
- **主题**：顶部“主题”提供经典白（默认）、Claude 暖色、羊皮纸、森林、暮色、蔷薇和跟随 DSH；预设支持明暗与跟随系统，当前浏览器记住选择。只改变起笔及其弹窗，不影响 DSH 全局配色或书稿内容。
- **看稿**：左侧作品 → 章节树，右侧正文，带状态、字数、更新时间。
- **改稿**：正文可直接编辑，停止输入后自动保存；保存走起笔自己的写入约定（重算字数、刷新作品总字数）。
- **管稿**：作品新建/设置/删除；章节新建、改名、改状态、上移/下移、删除；版本列表与恢复。
- **人物 AI**：“人物”页可分析当前章、全书或所选起止章，或按一句话描述生成一个角色；支持模型思考档位，候选先预览、编辑和勾选后确认入库，同名只跳过不覆盖。全书与范围分析由作者手动逐批推进，每批一次模型调用；长章节从上次偏移继续，合并时保留已编辑字段。每次最多确认导入30人，剩余候选继续保留。
- **设定与资料**：大纲增删改；人物设定与动态账本；分卷、章节摘要、写作状态与伏笔账本。
- **检索与导出**：关键词检索 + 起笔 BM25 知识库（可重建索引）；整本导出 Markdown / TXT。
- **蒸馏作者**：上传 TXT / MD / HTML / JSON / EPUB 样章，解析成素材；把 DSH Agent 生成的三段结果保存为版本，可回滚、可绑定到作品。绑定后 Agent 生成/润色时会自动遵循该版本的写作 Skill。
- **让 Agent 写**：`qibi_chapter(action=write/create)` 等工具可以把一章写进起笔；面板会自己发现变化并提示刷新。
- **写作辅助**：正文上方按姓名/别名识别「本章出场」人物，点一下插入光标处；细纲锚点用标题前 8 字（或自定义文字）在正文定位，已写到的直接跳转；`Alt+F` 专注模式；作品与章节各自筛选、独立滚动；`Ctrl+Z` / `Ctrl+Y` 撤销重做（含 AI 写入与排版等程序化改动）。
- **AI 写作**：除整章/选区/分析三组动作外，还有「创作顾问」；补充要求有常用预设；结果写回正文后通知条可一键撤销。每次完整生成都会留在抽屉的「生成历史」里（本机保存，关闭抽屉不丢），应用时另在起笔版本历史写一条「AI 生成 · 模式名」。本章没有细纲时，会明确依据总纲、各章摘要、人物、伏笔与前一章正文生成。
- **生成参数**：AI 写作顶部可按当前模型能力选择思考强度，默认跟随宿主设置。生成和继续生成共用选择，按模型在本机记忆，不改变全局默认模型或强度；不支持调节时说明原因。
- **不重复劳动**：不在插件里复刻 AI 生成。起笔负责正典与编辑器，DSH 负责会话与模型。

## 它是怎么连上起笔的

插件是一个独立的 DSH 包，装进 DSH 的 profile，与 `起笔.exe` **没有进程关系**，不需要起笔正在运行：

- Windows 默认使用 `D:\dsh-qibi\data\novelforge.db`；没有 D 盘时回退到用户目录下独立的 `dsh-qibi/data`。首次自动初始化空白库，只创建本地作者，不带任何小说。
- 面板“数据位置”可以填写或选择目录、创建空白库或连接已有库，并通过 DSH 配置服务保存选择；不会自动导入旧测试库，不搬移或覆盖已有书稿。
- 安装包不含小说正文、用户数据库、备份或密钥。
- 起笔与插件可以同时开着：库是 WAL 模式，写操作带 `busy_timeout` 与短事务。
- 卸载插件不影响起笔；删掉起笔只是让面板显示「没有找到起笔数据库」。

## 边界与安全

- **只动内容表**：`novels` / `chapters` / `outlines` / `characters` / `chapter_revisions` / `kb_chunks` 等。绝不读取 `users.*_api_key_enc`（那是 AES-GCM 密文，插件也不需要密钥）。
- **写前必备份**：每次覆盖正文前先写一条 `chapter_revisions`（起笔自带「最近 50 版」保留策略），可在起笔里回滚；删除章节前会把正文另存到 `dataDir/chapter-backups/`。
- **不静默覆盖**：保存带 `updated_at + 正文哈希` 的乐观锁，校验与写入在同一个 `BEGIN IMMEDIATE` 事务内完成。若起笔那边已经改过这一章，插件拒绝写入并提示你选择重载或强制覆盖。大纲、人物、分卷、摘要与写作状态也有字段级乐观锁；资料页签保存冲突会提示重新加载。
- **写入保护**：Agent 读取被截断时不会拿到 token；已有正文必须带 token 才能写；空内容覆盖与「疑似截断的前缀写回」会被拒绝。AI 输出未完整结束时只能复制，不能写回正文；达到模型长度上限时可点「继续生成」接着写完。
- **可关闭写入**：`config.allowWrite: false` 后，面板与工具都会拒绝一切写操作，只保留读取。
- **不改已有库结构**：只有目标文件不存在时才初始化空库表结构；连接已有数据库时不建表、不加列、不迁移。
- **归属边界**：作品/章节/大纲/人物/分卷都按当前作者校验；换一个 `userId` 既看不到也写不了别人的作品。

## 已知限制

- 起笔自带的 BM25 检索（`kb_chunks`）由插件写入时同步更新索引；若你在起笔里大批量重建索引，请以起笔侧结果为准。
- 地图编辑器、管理员与公网相关功能不在插件范围内。
- 蒸馏作者不在插件里调用模型：面板负责素材与版本，生成由 DSH Agent 通过 `qibi_distill` 完成。
- 章节可上移/下移；分卷可新建与修改，但「章节归属哪个分卷」仍按起笔数据只读展示。
